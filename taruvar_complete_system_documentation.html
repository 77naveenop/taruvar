1. Executive Summary & Core Mission

TARUVAR ("One Person. One Tree. / एक व्यक्ति, एक पेड़") is a technology-enabled grassroots environmental organization and public movement built on the core belief that planting a tree is only the beginning.

Traditional environmental drives focus solely on the gross number of saplings planted during one-day events, resulting in over 80% sapling mortality due to lack of ongoing care. Taruvar changes this through individual guardianship (Paalna / देखभाल), requiring ongoing nurturing, photographic documentation, and a mandatory 5-month growth verification cycle.

The 5-Step Taruvar Framework

  1. 1. Plant (पौधा लगाना): Individual plants a climate-appropriate sapling, selects species, and uploads photo proof.
  2. 2. Care (देखभाल / Paalna): Guardian provides water, nutrients, and protection throughout seasonal heat and winter.
  3. 3. Document (तस्वीर व लॉग): Adopter uploads monthly growth progress photos and observations.
  4. 4. Grow (निरंतर विकास): Tree progresses through Month 1 to Month 5 verification milestones.
  5. 5. Inspire (प्रेरणा): Verified trees earn the official Level 5 Eco-Guardian Badge and rank on the community feed.

3.2 Printable PVC Eco-Guardian Card Specifications

  • Standard Card Dimensions: 85.6mm × 53.98mm (CR80 standard credit card / lanyard badge size).
  • Front Side: Official Holographic Badge, Guardian Name, Member ID, Tree Passport ID, Species, Location, Live Scannable QR Code, Verification Status.
  • Back Side (Flip View): 5-Month Milestone Verification Stamp Log (`Month 1` through `Month 5`) + Official Guardian Caretaker Oath.

  • 1-Click Physical Print: Integrated with browser @media print CSS isolating the card for instant physical PVC card printing.

4. Database Architecture & Schema (Supabase)

4.1 Table: pledges (Tree Adoptions)

CREATE TABLE public.pledges (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT,
  tree_type TEXT NOT NULL,          -- 'Neem', 'Peepal', 'Banyan', 'Mango', 'Gulmohar'
  tree_name TEXT,                   -- Nickname e.g. 'My Peepal Guardian'
  location TEXT,                    -- e.g. 'Sector 4 Green Park, Delhi NCR'
  plantation_photo TEXT NOT NULL,   -- Photo proof
  status TEXT DEFAULT 'pending',    -- 'pending', 'approved', 'rejected'
  verified_months INT DEFAULT 1,    -- 1 to 5 milestones completed
  upvotes_count INT DEFAULT 0,      -- Community ranking counter
  member_id_code TEXT,              -- 'TRV-IND-2026-XXXX'
  tree_id_code TEXT,                -- 'TRV-TREE-XXXX'
  created_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE public.pledges ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public can view approved pledges" ON public.pledges FOR SELECT USING (true);
CREATE POLICY "Authenticated users can insert pledges" ON public.pledges FOR INSERT WITH CHECK (true);
CREATE POLICY "Admins can update pledges" ON public.pledges FOR UPDATE USING (true);

4.2 Table: monthly_reports (5-Month Growth Logs)

CREATE TABLE public.monthly_reports (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  tree_id UUID REFERENCES public.pledges(id) ON DELETE CASCADE,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  month_number INT NOT NULL,        -- 1, 2, 3, 4, 5
  photo_url TEXT NOT NULL,          -- Monthly growth photo
  notes TEXT,                       -- Observations (height, compost, watering)
  status TEXT DEFAULT 'pending',    -- 'pending', 'verified', 'rejected'
  submitted_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE public.monthly_reports ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public read monthly_reports" ON public.monthly_reports FOR SELECT USING (true);
CREATE POLICY "Users can insert monthly_reports" ON public.monthly_reports FOR INSERT WITH CHECK (true);

8. Step-by-Step Operational Workflows

8.1 Tree Adoption to Verified Badge Lifecycle

  1. Step 1 (Adoption): User navigates to /adopt, chooses species, enters nickname/location, and uploads a mandatory plantation photo.
  2. Step 2 (ID Generation): System immediately generates Member ID (TRV-IND-2026-XXXX) and Tree Passport ID (TRV-TREE-XXXX), rendering the printable PVC ID card.
  3. Step 3 (Admin Review): Admin opens /admin, reviews the photo proof, and approves the adoption.
  4. Step 4 (5-Month Progress Logs): Every 30 days, the user uploads Month 1 to 5 growth photos in their Profile.
  5. Step 5 (Verification & Badges): Admin verifies monthly progress logs, advancing the user's status to Level 5 Verified Eco-Guardian.
